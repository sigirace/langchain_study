## 8. Private GPT

### 8.1 HuggingFaceHub

📌 **HuggingFace 모델을 사용하는 방법**

1. transformers 라이브러리의 pipeline API 사용

```python
from transformers import pipeline

messages = [
    {"role": "user", "content": "Who are you?"},
]
pipe = pipeline("text-generation", model="mistralai/Mistral-7B-Instruct-v0.3")
pipe(messages)
```

- transformers 라이브러리의 pipeline API를 사용하는 간단한 방식
- pipeline은 다양한 작업(예: 텍스트 생성, 감정 분석 등)에 대해 손쉽게 모델을 사용할 수 있도록 해줌
- pipeline 함수 안에 작업 유형과 모델 이름만 지정하면 되기에 설정이 간편하고, 빠르게 결과를 얻을 수 있다는 장점이 있음

2. 모델과 토크나이저를 직접 로드하여 사용

```python
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("mistralai/Mistral-7B-Instruct-v0.3")
model = AutoModelForCausalLM.from_pretrained("mistralai/Mistral-7B-Instruct-v0.3")
```

- transformers 라이브러리에서 AutoTokenizer와 AutoModelForCausalLM을 사용하여 토크나이저와 모델을 직접 로드하는 방식
- 모델의 세부 동작을 더 세밀하게 제어할 수 있음 (ex) 입력을 직접 토큰화하고, 출력 토큰을 디코딩하는 과정 등을 커스터마이즈
- 즉, 파이프라인보다 더 많은 유연성을 제공

3. huggingface_hub의 InferenceClient 사용

```python
from huggingface_hub import InferenceClient

client = InferenceClient(
    "mistralai/Mistral-7B-Instruct-v0.3",
    token="hf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
)

for message in client.chat_completion(
    messages=[{"role": "user", "content": "What is the capital of France?"}],
    max_tokens=500,
    stream=True,
):
    print(message.choices[0].delta.content, end="")
```

- huggingface_hub의 InferenceClient를 사용하여 모델에 대한 API 호출을 수행
- 로컬에서 직접 모델을 실행하는 대신 Hugging Face 서버에서 모델이 실행됨
- 로컬에서 대형 모델을 실행할 수 없는 경우에 유용하며, 스트리밍 기능을 통해 실시간으로 결과를 받아볼 수 있음

📌 **Online vs Offline**

- 1번, 2번 방식은 transformer API를 통해 Huggingface의 모델을 초기 1회 다운로드 받음
- 다운로드 받은 파일은 cache 디렉토리에 저장됨
- 3번 방식은 매번 API 호출

### 8.2 HuggingFacePipeline

📍 **HuggingFacePipeline.from_model_id**

- task
  - text-generation
  - text2text-generation, summarization

📍 **text-generation vs text2text-generation**

1. text-generation

   - 주어진 입력 텍스트에 이어지는 텍스트를 생성
   - 문장 완성, 이야기 생성, 대화형 AI

2. text2text-generation
   - 입력 텍스트를 바탕으로 변형된 텍스트를 생성하는 작업
   - 텍스트 요약, 번역, 질문 생성 및 응답, 문법 교정
