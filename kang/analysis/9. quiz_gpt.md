### 9.3 Questions Prompt

📍 **StreamingStdOutCallbackHandler**

- LangChain 라이브러리에서 제공하는 콜백 핸들러

### 9.6 Caching

- document가 바뀌지 않는다면 chain이 수행되지 않도록 함

📍 **st.cache_data**

- 데코레이터로 적용된 함수의 argument의 hash 값을 알아냄
- hash 값을 disk나 어떠한 저장소에 저장해 놓았다가 다음 실행때 체크
- 단, argument가 mutable일 경우 hash 값을 만들 수 없음
  - mutable일 경우 앞에 \_를 붙여줌
  - 그리고 hash 값을 만들어줄 다른 argument 사용

📍 **Mutable vs Immutable**

1. Mutable 객체

   - 리스트 (list)
   - 딕셔너리 (dict)
   - 세트 (set)

2. Immutable 객체
   - 튜플 (tuple)
   - 문자열 (str)
   - 숫자형 (int, float, etc.)

### 9.8 Function Calling

📍 **Function calling**

> llm으로 수행할 수 없는 API 호출 등을 내부에서 수행할 수 있도록 함

- schema를 만들어서 해결
  - name
  - description
  - parameters
  - required

🌈 **Example**

1. client가 특정 지역의 날씨를 GPT에게 물어봄
   - 날씨 API 함수가 내부에 있다고 GPT에게 알려줌
   - 날씨 API 함수의 parameter들을 schema로 정의하여 전달
2. GPT가 판단하기에 자신이 수행할 수 없는 task임
   - 전달받은 function_call 중에 사용할 수 있는 함수를 찾음
   - parameter에 대한 argument를 생성함
   - client에게 전달
3. Clinet는 GPT의 response를 확인하여 내부 API function 수행
   - API 결과를 다시 GPT에게 전달
4. GPT 문장 생성
