### 12.1 Your First Agent

📍 **agent vs function calling**

- Function Calling: 단일 작업 또는 명확히 정의된 API 호출을 통해 특정 기능을 수행
- Agent: 복잡한 문제 해결을 위해 여러 툴과 함수들을 조합하여 자율적으로 작업을 수행
