### 12.1 Your First Agent

📍 **agent vs function calling**

- Function Calling: 단일 작업 또는 명확히 정의된 API 호출을 통해 특정 기능을 수행

### 12.2 How Do Agents Work

📌 **Agent pesudo code**

```python
next_action = agent.get_action(...)
while next_action != AgentFinish:
    observation = run(next_action)
    next_action = agent.get_action(..., next_action, observation)
return next_action
```

- agent에 input을 전달할시, runtime은 LLM으로부터 get_action을 받아오려함, 즉 LM에게 어떤 액션을 할 것인지 선택하라고함
- LLM이 끝남을 의미하는 AgentFinish로 응답하지 않는다면
  - LLM이 선택한 action을 수행함

🌈 **프롬프트 예시**

[PART1]

```
Respond to the human as helpfully and accurately as possible. You have access to the following tools:

Sum Calculator: Sum Calculator(a, b) - Use this to perform sums of two numbers. This tool take two arguments, both  should be numbers. till finish., args: {{'a': {{'title': 'A'}}, 'b': {{'title': 'B'}}}}

Use a json blob to specify a tool by providing an action key (tool name) and an action_input key (tool input).

Valid "action" values: "Final Answer" or Sum Calculator

Provide only ONE action per $JSON_BLOB, as shown:

'''
{
  "action": $TOOL_NAME,
  "action_input": $INPUT
}
'''
```

- 프롬프트에 구현한 함수를 전달함
- action 키(=tool 이름)와 action_input 키(=tool 입력값)를 제공하는 Json blob을 사용하여 수행할 tool을 지정
- LLM에게 Json의 action에 유효한 key만을 사용하도록 설정
  - Final Answer
  - Custom function
- 하나의 action만을 생성

[PART2]

````
Follow this format:

Question: input question to answer
Thought: consider previous and subsequent steps
Action:
'''
$JSON_BLOB
'''
Observation: action result
... (repeat Thought/Action/Observation N times)
Thought: I know what to respond
Action:
'''
{
  "action": "Final Answer",
  "action_input": "Final response to human"
}
'''

Begin! Reminder to ALWAYS respond with a valid json blob of a single action. Use tools if necessary. Respond directly if appropriate. Format is Action:```$JSON_BLOB```then Observation:.
Thought:
````

- Question과 Thougth 두가지 로깅 메시지 출력
- LLM이 끝날 때(Final Answer) 까지 action을 반복
- 최종 포맷에 대한 제약

### 12.3 Zero-shot ReAct Agent

📍**Zero-shot ReAct**

- 다양한 agent의 유형 중 하나
- 가장 범용적인 목적의 agent
- OpenAI를 사용하지 않아 GPT3.5-trubo, GPT4와 같은 채팅모델을 사용하지 않아도 사용할 수 있음
- Structured input ReAct는 복수의 입력을 가질 수 있으나 zero-shot은 그렇지 않음

📍**OpenAI Fucntions**

- LLM으로부터 출력 값을 강요하는 것보다 나은 함수 호출 방식 사용
