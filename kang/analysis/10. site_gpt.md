📍 **AsyncChromiumLoader**

> Playwright 라이브러리에서 Chromium 브라우저를 비동기적으로 제어하는 기능

- 📜 [langchain-공식문서](https://python.langchain.com/v0.2/docs/integrations/document_loaders/async_chromium/)
  - playwright와 beautiful soup package가 설치 되어있어야 함
  - playwright: 웹 애플리케이션 테스트와 자동화를 위한 도구
- Chromium 브라우저
  - Google Chrome의 오픈 소스 기반 브라우저
  - Playwright는 이 브라우저를 제어할 수 있으며, 이를 통해 웹 페이지 자동화, 스크린샷 캡처, 웹 크롤링 등을 수행
- Playwright의 비동기 제어
  - Playwright는 Python에서 비동기 코드를 지원
  - 여러 웹 페이지를 동시에 크롤링하거나 테스트할 떄 유용
- 헤드리스 모드
  - headless=True 옵션을 사용하면 브라우저가 그래픽 사용자 인터페이스(GUI) 없이 백그라운드에서 실행
  - 서버 환경에서 자동화 작업을 수행할 때 주로 사용

```
# 가상환경 실행
source env/bin/activate

# playwright 설치
playwright install
```

### 10.2 SitemapLoader

📍 **SitemapLoader**

> 웹 사이트에 sitemap이 있는지 확인

- 너무 빠른 시간에 요청을 한다면 차단당하기에 일정한 간격으로 요청을 보냄(default=1초)

📌 **요청 시간을 변경하는 방법**

```python
loader = SitemapLoader(url)
loader.requests_per_second = 1
```
