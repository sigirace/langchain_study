### 11.1 Audio Extraction

📌 **영상에서 비디오를 추출**

1. cli

```
ffmpeg -i [input mp4 file] -vn [output mp3 file]
```

2. code

```python
import subprocess

def extract_audio_from_video(video_path, audio_path):
    command = ["ffmpeg", "-i", video_path, "-vn", audio_path]
    subprocess.run(command)
```

### 11.6 Refine Chain Plan

📌 **st.status를 줄이는 방법**

1. as-is

```python
with st.status("Loading1..."):
    pass
with st.status("Loading2..."):
    pass
with st.status("Loading3..."):
    pass
```

2. to-be

```python
with st.status("Loading1...") as status:
    status.update(label="Loading2...")
    status.update(label="Loading3...")
```

- 한곳에서 변화가 일어남
